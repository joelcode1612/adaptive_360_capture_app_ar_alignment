# 2026-11-05

- Performed a full read-only technical audit / FYP completion assessment of the project.
- Findings: two production launch paths (AR core module `features/capture` → CaptureModuleScreen; Virtual Tour 30-node → VirtualTourCameraScreen) plus a Guided Flow (CaptureFlowScreen). Flutter frontend compiles cleanly (`flutter analyze` = 4 minor issues) and resolves all deps.
- Backend (FastAPI + SQLAlchemy async, `backend/src/sitesense`) implements capture ingestion only: create tour, upload single capture (multipart), finalise → writes stitch manifest, marks `stitch_pending`. **No stitching/panorama worker exists** (no OpenCV/cv2 anywhere); the `stitching`/`stitched` enum states are unreachable.
- Frontend↔backend protocol mismatch: FE remote source calls `/api/v1/panoramas/stitch` and `/api/v1/virtual-tours/{tourId}/submit`; backend exposes `/api/v1/virtual-tours`, `/captures`, `/finalise`. Not wired; FE falls back to `LocalVirtualTourRemoteDataSource` (simulated) unless `VIRTUAL_TOUR_API_BASE_URL` is set.
- No Supabase/RLS/postgrest anywhere (default DB is SQLite `sqlite+aiosqlite:///./var/sitesense.db`); auth is a dev-only `X-User-Id` header shim gated by `SITESENSE_ALLOW_DEVELOPMENT_IDENTITY`.
- No ML/AI or SHAP. "Analysis" is rule-based CV heuristics (mean luminance, Laplacian variance, gradient edge share, entropy) in `domain/quality/image_analysis.dart` + `decision_rules.dart`, with provisional, uncalibrated thresholds.
- 30-node sphere (`virtual_tour_capture_engine.dart`, nodeCount=30) vs 26-target plan (`plan26`) for the guided flow; `planAll` derives row counts from FOV/overlap.
- Testing: 30+ Flutter unit-test files present; `flutter test` could NOT run here (flutter_tester WebSocket harness failure in this sandbox). Backend pytest fails to collect (deps not installed: PIL, pytest-asyncio). `tool/verify_all.dart` is stale/outdated (references removed run*Checks functions).
- Estimated overall completion ≈ 52% (provisional). Core gap: real stitching pipeline + FE↔backend integration + production auth + test execution.
